# RM 计算模型说明

## 单组计算

输入重量、完成次数和 RIR。有效次数为：

```text
有效次数 = 完成次数 + RIR
```

系统使用以下 8 个公式分别估算 1RM：

- Epley
- Brzycki
- Lander
- Lombardi
- Mayhew
- O'Conner
- Wathan
- NSCA / Baechle

默认启用全部公式，并去掉一个最高值和一个最低值，对剩余结果取平均。公式配置固定在源码默认配置中。

当输入为 1 次且 RIR 为 0 时，直接使用输入重量作为 1RM，避免出现明显高估。

## 多组计算

正式组分别进行单组估算，再按重量加权得到基础估算，并根据组数、休息时间和表现稳定性提供有限修正。总修正上限为 15%。

热身组不参与计算；当前界面只允许先填写第一组，再复制添加后续组，RIR 不复制。

## 参数性质

8 个单组公式具有公开数学依据；组数贡献、休息贡献、稳定性贡献及总修正上限属于产品 V1 的经验参数，不是统一公认的运动科学标准。
