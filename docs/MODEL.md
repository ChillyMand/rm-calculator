# RM 计算模型说明

## 单组计算

输入重量、完成次数和 RIR。有效次数为：

```text
有效次数 = 完成次数 + RIR
```

系统使用以下 8 个公式分别估算 1RM：

- Epley
- Brzycki
- Lander
- Lombardi
- Mayhew
- O'Conner
- Wathan
- NSCA / Baechle

默认启用全部公式，并去掉一个最高值和一个最低值，对剩余结果取平均。公式配置固定在源码默认配置中。

当输入为 1 次且 RIR 为 0 时，直接使用输入重量作为 1RM，避免出现明显高估。

## 多组计算

生产页面使用 `multiset-capacity-v3.0.0-beta`。输入为同一动作、同一重量下的 2～8 个正式组，模型根据每组完成次数和 1～5 分钟组间休息递推残留疲劳，再利用最后一组 RIR 锚点反推训练开始时的未疲劳次数容量和 e1RM。

默认快捷模式仅要求选择最后一组余力；前组未知 RIR 不会被当成 0。高级模式允许逐组填写 RIR 和休息。6～8 组及卧推之外的动作均显示对应实验警告；9 组以上、变重训练和超出次数/休息范围的输入不输出主估算。

V3 不使用组数奖励、长休息奖励、稳定性奖励，也不以最佳单组结果兜底。模型拒绝输出主估算时，候选调试值不会展示给用户。

## 参数性质

8 个单组公式继续只用于单组模式。多组 V3 的参数来自公开卧推研究和明确的工程保护阈值，属于文献驱动实验模型，不是已经完成个人准确率验证的生理定律。页面展示的假设范围不是置信区间或个人预测区间。
