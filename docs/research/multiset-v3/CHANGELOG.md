# 更新记录

## V3.0.0-beta · 2026-09-26

交付研究规格与独立实现，尚未合并生产、部署或推送。

- 将目标明确为训练开始时的未疲劳e1RM，而非训练容量评分或PR。
- 用实际完成次数和组间休息递推疲劳，不再添加组数、休息、稳定性奖励。
- 未知RIR不再按0；快捷模式仅要求末组余力，接近力竭明确为0～1区间。
- 末组必须有锚点，避免仅第一组有RIR时后组不影响估值却被称多组融合。
- 用公开卧推研究汇总数据拟合β、τ，并采用带1次边界的线性次数—负重曲线；不沿用旧8公式平均。
- 引入可重复参数校准、逐研究留出和7组域外检查。
- 支持2～8组；6～8组、其他动作、非力竭迁移均有显式警告；9组拒绝，不能静默截取。
- 原始100kg×5、5、3示例允许新增观测使估计略调整，不强行规定只涨不跌，也不生成PR。
- 区分正常实验、拟合偏差、跨动作迁移、6～8组外推、需复核、不支持、信息不足等状态。
- 敏感性范围逐情景标记跨域与失配，不冒充个人预测区间。
- 增加自动化测试、23项展示案例及35项组数×休息组合软件检查。
